What we build

  • Custom web applications

    Business platforms that many organizations and roles can share safely, with reporting, document handling and interfaces that work on a phone. We build mainly in Python and TypeScript.

  • Systems integration

    Connections between your software and accounting, payment, vehicle-tracking and partner systems, whether they exchange data through an API or through files.

  • AI-assisted applications

    Software that reads documents and extracts their data, classifies records, and answers questions using current language models, with a person reviewing the output where accuracy matters.

  • English and Spanish products

    Applications designed from the first screen for people who work in English, Spanish or both, including other languages when a project needs them.

Who does the work

AssertBits is owned and run by Raul Menendez, a software engineer based in Miami. He has designed and shipped a complete multi-organization logistics platform, including document reading with AI, accounting and payment integrations, and a mobile app for drivers.

Every engagement is led by the engineer who writes the code. You talk to the person building your software, and you receive tested, documented work that your own team can maintain.

How an engagement runs

We start with a short written scope and a fixed first milestone, so you see working software early. After that we deliver in small increments, each one reviewed with you before the next begins.
