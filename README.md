# assertbits-site

Public website for AssertBits LLC, served by GitHub Pages at https://assertbits.com.

A single static page: `index.html`. No build step. `CNAME` tells GitHub Pages which domain to serve.

To preview locally: `python3 -m http.server 8765` and open http://127.0.0.1:8765/.

Everything in this repository is public. Company records and working notes live in the private `assertbits` repository.
